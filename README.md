TasteCraft 🍽️

TasteCraft is a modern and responsive recipe discovery web application that helps users find delicious meals based on the ingredients they already have.
The project focuses on creating a smooth and visually appealing user experience using modern frontend technologies.

✨ Features
🔍 Search meals by ingredient
🍲 Dynamic recipe cards
📱 Fully responsive design
🎨 Modern UI built with Tailwind CSS
🖼️ Community meal suggestion slider using Swiper.js
⚡ Smooth animations and transitions
📌 Sticky navigation bar
💬 Interactive modal dialog
🌐 Clean and organized layout

🛠️ Technologies Used
HTML5
Tailwind CSS
JavaScript (Vanilla JS)
Swiper.js
ScrollReveal.js
Remix Icons
Google Fonts
